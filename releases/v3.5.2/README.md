# MOEX Research Robot v3.5.2

Архив стабильной версии, используемой как исходная база проекта Unified Portfolio System.

## Содержимое

- `moex_trading_robot_research_v3_5_2.zip` — архив версии v3.5.2, загруженный владельцем репозитория.

Исходный код пока не распакован в корень репозитория. Разработка следующей версии должна выполняться в ветке `develop` после отдельной проверки архива на секреты, runtime-файлы и воспроизводимость тестов.

## Ограничения

Версия предназначена для исследовательского режима и T-Invest Sandbox. Реальный торговый контур не принят в эксплуатацию. Полный естественный цикл BUY → SELL, восстановление ownership позиции, интерфейс виртуального портфеля и сохранение PRIMARY/SHADOW остаются задачами ветки v3.5.x.
