# MOEX Research Robot v3.5.2

Зафиксированная исходная версия, использованная как база проекта Unified Portfolio System.

## Содержимое

- `source-v3.5.2.zip` — очищенный архив исходного кода;
- `SHA256SUMS.txt` — контрольная сумма архива;
- каталог `current/` в корне репозитория — распакованный рабочий исходный код этой версии.

## Проверка до публикации

- `python -m compileall -q .` — успешно;
- `python -m pytest -q` — `89 passed in 3.12s`;
- версия ядра — `0.3.5.2`;
- GUI — `MOEX Research Robot v3.5.2`;
- `.env`, токены, журналы, SQLite/state-файлы и локальные кэши исключены.

## Ограничения

Версия предназначена для исследовательского режима и T-Invest Sandbox. Реальный торговый контур не принят в эксплуатацию. Полный естественный цикл BUY → SELL и восстановление ownership позиции остаются acceptance-задачами ветки v3.5.x.
