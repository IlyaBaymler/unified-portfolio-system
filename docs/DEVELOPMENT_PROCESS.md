# Development process

1. Новые изменения создаются в ветках `feature/...` от `develop`.
2. Вычислительное ядро тестируется отдельно от GUI.
3. Pull request должен содержать описание изменений, тесты, ограничения и сценарий ручной проверки.
4. После прохождения CI изменения объединяются в `develop`.
5. Релизная ветка создаётся только после acceptance-проверки.
6. `main` содержит последнюю принятую стабильную версию.
