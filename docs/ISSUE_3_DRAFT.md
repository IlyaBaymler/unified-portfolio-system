# v3.5.3: ownership recovery и безопасное закрытие непривязанных позиций

## Задача

Добавить безопасное разрешение состояния `UNATTRIBUTED_OPEN_POSITION`.

## Требования

- проверять совпадение `account_id`, `instrument_id`, `strategy_id`, `config_hash`, `interval`, `current_lots` и `target_lots`;
- требовать двойное подтверждение оператора;
- записывать полный audit trail;
- предоставлять отдельное безопасное закрытие непривязанной Sandbox-позиции;
- блокировать execution-loop до разрешения неоднозначности;
- не разрешать ручное редактирование state через GUI.

## Acceptance criteria

- отсутствующий, старый и повреждённый state обрабатываются fail-closed;
- восстановление переживает перезапуск;
- повторная заявка не создаётся;
- несовпадающая конфигурация не может принять позицию;
- закрытие позиции подтверждается broker reconciliation;
- события восстановления экспортируются в CSV/SQLite.
