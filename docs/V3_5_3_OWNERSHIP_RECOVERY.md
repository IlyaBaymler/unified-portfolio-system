# Ownership recovery v3.5.3

Процедура восстановления ownership должна быть отдельной управляемой операцией, а не автоматическим присвоением брокерской позиции текущей стратегии.

Проверяются account, instrument, strategy, config hash, interval, фактические и целевые лоты. При любом несовпадении исполнение остаётся заблокированным. Успешное восстановление требует двойного подтверждения и фиксируется в журнале событий.
