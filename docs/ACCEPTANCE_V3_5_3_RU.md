# Acceptance v3.5.3

Релиз принимается только после выполнения всех пунктов.

## Состояние и ownership

- открытая позиция имеет однозначного владельца;
- `UNATTRIBUTED_OPEN_POSITION` блокирует исполнение;
- восстановление ownership требует проверки всех идентификаторов и двойного подтверждения;
- после перезапуска ownership сохраняется;
- безопасное закрытие непривязанной позиции не создаёт дублей.

## Конфигурация стратегий

- PRIMARY/SHADOW сохраняются после перезапуска GUI;
- Dry-run и Sandbox имеют независимые настройки;
- runtime, GUI и журнал показывают одинаковые значения;
- активная сессия блокирует изменение настроек;
- повреждённая конфигурация приводит к fail-closed.

## Portfolio View

- корректно отображается пустой портфель;
- корректно отображаются несколько инструментов;
- видны cash, позиции, targets, ownership, pending orders и reconciliation;
- обновление не блокирует GUI;
- данные совпадают с broker response и SQLite-журналом.

## Регрессия

- `compileall` успешно;
- полный набор unit/integration tests успешно;
- dry-run без заявок;
- Sandbox BUY и SELL по одному лоту без дублей;
- сетевой разрыв и восстановление;
- проверка экспортированных событий;
- README, changelog и версия обновлены.
