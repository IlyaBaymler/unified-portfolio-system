# Ownership recovery acceptance

- открытая позиция без owner блокирует execution;
- восстановление допускается только при полном совпадении идентификаторов;
- требуется двойное подтверждение;
- все действия журналируются;
- перезапуск не теряет восстановленный ownership;
- несовпадающая конфигурация не может принять позицию;
- безопасное закрытие завершается broker reconciliation;
- повторная заявка не создаётся.
