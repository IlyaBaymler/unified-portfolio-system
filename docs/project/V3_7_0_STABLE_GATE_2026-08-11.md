# v3.7.0 Stable gate — 2026-08-11

Следующий этап после принятия `v3.7-beta1` — `v3.7.0 Stable`.

Это release-qualification этап без расширения торговой функциональности.

## Freeze

Не добавлять:

- multi-instrument execution;
- новые стратегии;
- новый PortfolioState schema;
- short positions;
- real-account execution;
- portfolio allocation/rebalancing.

## Основной gate

- beta1 acceptance complete;
- полный regression PASS;
- crash/recovery PASS;
- migration regression PASS;
- clean upgrade/install PASS;
- backup/restore/support bundle PASS;
- standalone without Python PASS;
- rollback PASS;
- release hygiene/secret scan PASS;
- 0 duplicate submit;
- 0 fill without canonical reconciliation;
- 0 execution without Risk accounting;
- финальный Sandbox burn-in 24–48 h рекомендуется.

После `v3.7.0 Stable` начинается `v3.8.0 Multi-Instrument Sandbox`.
