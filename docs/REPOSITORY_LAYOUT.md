# Repository layout

```text
.
├── current/                    # актуальная стабильная исходная версия
├── docs/                       # архитектура, планы и протоколы
├── releases/                   # зафиксированные исходные архивы версий
├── .github/workflows/          # автоматические проверки
├── README.md
├── ROADMAP.md
├── SECURITY.md
└── .gitignore
```

## Ветки

- `main` — последняя проверенная стабильная база;
- `develop` — интеграционная ветка следующей версии;
- `release/v3.5.2` — зафиксированный релиз v3.5.2;
- будущие функции разрабатываются в короткоживущих ветках `feature/...` и попадают в `develop` через pull request.

## Файлы, запрещённые к публикации

- `.env` и токены;
- идентификаторы реальных и Sandbox-счетов;
- `robot_state.json` и диагностические state-файлы;
- `trading_events.db`;
- рабочие журналы;
- виртуальные окружения, кэши и результаты локальной сборки.
